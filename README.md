# 🦖 CHRONO-RUN

A fast, minimalist Chrome Dino dark-mode endless runner built with clean Canvas2D physics, procedural 8-bit web audio, progressive difficulty scaling, mobile touch controls, gamepad support, and unlockable custom skins.

---

## 🕹️ Controls
- **Jump / Double-Jump:** `Space` / `↑` / `W` / `Click` / `Gamepad A`
- **Duck / Fast-Drop:** `↓` / `S` / `Gamepad B`
- **Mobile:** On-screen `▲` and `▼` touch buttons or swipe gestures.
- **Custom Skins:** Click `SKIN` button to toggle between Classic, Cyber Neon, Gold Phantom, and Emerald Bot.

---

## 🚀 Deployment
Deploy instantly to **Vercel** or **GitHub Pages**:
- **Static files:** `index.html`
- **Zero dependencies & 0ms load times.**
